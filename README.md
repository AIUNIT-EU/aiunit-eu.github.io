# aiunit-eu.github.io

Veröffentlichte App-Dateien der PWA **ICH** unter https://aiunit-eu.github.io/ich/.

- Nur statische App-Dateien. Keine Nutzerdaten, keine Schlüssel, keine Doku.
- Alle Inhalte der App bleiben verschlüsselt auf dem Gerät der Nutzerin oder des Nutzers.
- Quelle und führende Fassung: privates Repository `AIUNIT-EU/ICH-App` (Branch `ICH-App`), erstellt mit `scripts/build-web.sh`.
- Stand: App 0.7.0, Quell-Commit dd7874b.
